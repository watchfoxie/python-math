Exact Matrix Determinant

Write a program that computes the determinant of a square matrix whose entries are exact rational numbers, and prints the result exactly, as a fraction in lowest terms. The elimination must not use floating point anywhere: rounding would turn the printed "exact" value into a lie. Work with exact rationals (fractions.Fraction, for instance) and Gaussian elimination with row pivoting: at step k pick, among the rows k..n-1, the entry of largest absolute value in column k as pivot; if that entry is zero, the determinant is zero and the program may stop early.

Input: The first line contains n, the order of the matrix (1 <= n <= 50). Each of the next n lines contains n entries separated by spaces. An entry is an integer ("7", "-3"), a fraction ("1/2", "-4/9") or a decimal ("0.25", "-1.75"). Decimals are read as exact rationals, so "0.25" means exactly 1/4.

Output: The determinant on a single line. If it is an integer, print it as such (minus sign included). Otherwise print it as "p/q" in lowest terms, the sign carried by the numerator.

Examples

Example 1:
input:
3
1 2 3
4 5 6
7 8 10

output:
-3

Example 2:
input:
2
1/2 1/3
1/3 1/4

output:
1/72

Example 3:
input:
1
0.125

output:
1/8

Remarks: The matrix in Example 1 is invertible; replacing its 10 with a 9 would make the three rows linearly dependent and the determinant 0. Since no floating point takes part in the computation, the result stays trustworthy no matter how ill-conditioned the input is.
